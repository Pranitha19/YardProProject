# 🏡 YardProProject

A web‑based yard management / service scheduling application built with PHP following MVC architecture.
This project helps manage yard services (CRUD operations, service booking, admin management) using a structured backend and clean frontend.

# 📌 Features

✅ MVC (Model‑View‑Controller) Architecture
✅ Clean Routing & Controller Logic
✅ Database‑backed with Models
✅ Responsive UI (HTML / CSS)
✅ Yard Services Listing & Scheduling
✅ Form Validation & Sanitization
✅ Easily Extensible for future features

## Project Structure

📦 YardProProject
├── Controllers     # Application logic & routing
├── Models          # Database models & business logic
├── Views           # UI templates
├── Static          # CSS, JavaScript, Images
├── config          # Configuration files
├── db              # Database scripts / migrations
├── helpers         # Helper functions
├── index.php       # Front controller

## 🚀 Getting Started
# Prerequisites

Make sure you have the following installed:

✔ PHP 7.4+
✔ MySQL or MariaDB
✔ Apache / Nginx
✔ Compose

# Installation 

# 1.Clone the repo
git clone https://github.com/Pranitha19/YardProProject.git
# 2.Install dependencies
# 3.Configure database
Create a database (e.g., yardpro_db)
Update config/database.php with your credentials
# 4.Run migrations / import db
Import database from db folder
# 5. Start the server(we used Xaamp)to start the tomcat server and mysql

## 🛠 Usage

Once the application is running:

✨ Visit http://localhost:8000 in your browser
✨ Use the UI to browse services, register, login, schedule yard tasks
✨ Admin users can manage entries via dashboard pages
